Real Filing Reborn is a storage mod built around **Filing Folders** — items that each hold a massive quantity of a single item type — and **Filing Cabinets** to house them.

Connect multiple cabinets to a **Filing Index** to create a unified storage network, then hook that index into your favourite external storage mod for seamless access to everything.
