# Range Upgrades

Range Upgrades extend how far a <ItemLink id="filing_index" /> can reach to link Filing Cabinets. Install one by placing it in the upgrade slot inside the Filing Index GUI.

Only **one upgrade** can be installed at a time — higher tiers replace lower ones.

| Upgrade | Default Range |
|---------|--------------|
| Iron Range Upgrade | 16 blocks |
| Diamond Range Upgrade | 32 blocks |
| Netherite Range Upgrade | 64 blocks |

These values can be changed in the server config file.
