# Getting Started

The basic loop in Real Filing Reborn is simple: craft a **Filing Folder**, assign it to an item type, place it inside a **Filing Cabinet**, and start filling it up.

## 1. Craft a Filing Folder

<RecipeFor id="filing_folder" />

## 2. Assign the Folder

**Shift + Right-click** the Filing Folder in your hand to open its GUI. Place or shift-click the item you want to store into the assignment slot to lock the folder to that item type.
Alternatively, hold the item you wish to assign in your off-hand and an empty Filing Folder in your main hand, and right-click.

## 3. Craft a Filing Cabinet

<RecipeFor id="filing_cabinet" />

Filing Cabinets come in all wood variants and three types — they are functionally identical.

## 4. Insert the Folder

Right-click the Filing Cabinet with the Filing Folder in hand to insert it into an empty slot. Filing Cabinets hold up to **4 folders**.

## 5. Start Storing

Right-click the Filing Cabinet while holding items to insert them directly into a matching folder. To open the full cabinet GUI, **Shift + Right-click**.

From here, see [Filing Folders](filing_folders.md) to learn about upgrading your storage capacity, or [Filing Cabinet](filing_cabinet.md) for automation options.
