# Filing Cabinets

The Filing Cabinet holds up to **4 Filing Folders**. It is available in three types (Single - 1 Folder, Double - 2 Folders and Quad - 4 Folders) and in all wood variants — they are functionally identical.

## Interaction

| Action | Result |
|--------|--------|
| Right-click with items | Inserts held items into a matching Filing Folder |
| Right-click with a Filing Folder | Inserts the Filing Folder into an empty slot |
| Shift + Right-click | Opens the Filing Cabinet GUI |

## Automation

Filing Cabinets are fully compatible with **hoppers** and **pipes**. Items inserted from the outside are routed into the first matching Filing Folder automatically.

When connected to a <ItemLink id="filing_index" />, automation attached to the Filing Index can also route items into Filing Cabinets across the network.
